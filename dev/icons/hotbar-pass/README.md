## Reproduce and validate

`prepare.py` freezes briefs and source hashes for an unallocated pair of batches.
It is intentionally one-shot. `register.py` appends five cards without rewriting
earlier cards or feedback. Registration is separate from installation.

```text
python dev/icons/placeholder-pass/process.py --batch 115 --check
python dev/icons/placeholder-pass/process.py --batch 116 --check
npm run validate:icon-candidates
```

The shared atlas processor only splits, normalizes, crops, resizes and converts
generated artwork. It validates 256 px white alpha masks with at least 20 px
margins and exact matching PNG / WEBP / embedded-WEBP SVG pixels. New artwork is
generated by the image model, not redrawn by the processor.
