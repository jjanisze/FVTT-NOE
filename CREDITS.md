# Credits & asset sources

This file lists where the non-original content in this repository comes from, and under what
terms. The module's own code, configuration data, and documentation are MIT-licensed — see
[LICENSE](LICENSE). Everything below is either third-party, AI-generated, or derived from the
*Neuroshima Ostatnia Era* tabletop RPG, and is called out separately.

## Game system this overrides

This module modifies the [`dnd5e`](https://github.com/foundryvtt/dnd5e) system for
[Foundry Virtual Tabletop](https://foundryvtt.com/). Neither is redistributed here — install both
separately.

## Neuroshima Ostatnia Era content (compendia, terminology, rules)

*Neuroshima Ostatnia Era* (setting *Za Garść Gambli*) is a tabletop RPG published by
**Portal Games**. This module is an **unofficial, non-commercial fan conversion** of its rules to
the `dnd5e` engine. It is **not affiliated with, endorsed by, or produced in association with
Portal Games**. No scanned or verbatim pages of the book are redistributed; the compendia
(`packs/`) contain game-mechanical stats, translated terminology, and rules text needed to run
the system at the table — the same convention used by other fan-made 5e conversions of
non-5e-native games in the Foundry ecosystem. If you're a rights holder and have concerns about
specific content here, please open an issue (see [README.md](README.md#zgłaszanie-błędów)) — it
will be addressed promptly.

### Fallout 2 decoded sound library

A subset of the shipped firearm sounds (`sounds/firearms/`) is decoded from the original
**Fallout 2** (Interplay / Black Isle Studios; property of Bethesda Softworks) game data, sourced
from a fan audio rip hosted at
[spriters-resource.com/pc_computer/fallout2](https://sounds.spriters-resource.com/pc_computer/fallout2/).
This is used here for **non-commercial fan purposes only**, consistent with how the wider
retro-gaming/modding community treats these rips. Source-identification notes and per-file
provenance live in [`dev/audio/lib/f2/DECODED_SOUND_MAP.md`](dev/audio/lib/f2/DECODED_SOUND_MAP.md).
If Bethesda or a rights holder would like these files removed, please open an issue — they will
be pulled without argument.

## Icons

Most item/ability/status icons are AI-generated (Google Gemini and OpenAI ChatGPT image models),
prompted for a flat, minimal, single-color silhouette style matching the base `dnd5e` icon set,
then normalized by a local script. Pipeline and prompt details:
[`dev/icons/Pipeline.md`](dev/icons/Pipeline.md). Status-effect icon spec:
[`icons/statuses/ASSETS.md`](icons/statuses/ASSETS.md).

On 2026-10-12, 31 exact GM-approved glyphs from Batches 60–62 were installed as
lossless WEBP rasters and theme-aware SVG wrappers embedding WEBP masks. These
OpenAI-generated glyphs retain the approved pixels; selections and source hashes
are recorded in `dev/icons/review/candidates/batch-63/installed.json`.
Batch 63's new atlas prompts and targeted Samuraj correction are archived beside
their review candidates; pending candidates are not shipped until approved.

A further 19 exact GM-approved Batch 63 glyphs were installed on 2026-10-12 using
the same lossless WEBP/SVG process. Per-file selections and hashes are in
`dev/icons/review/candidates/batch-64/installed.json`. Batch 64's generic prompts
and exact revision references are archived beside its review candidates.

Fifteen GM-approved Batch 64 glyphs were installed on 2026-10-12 as lossless
WEBP rasters and SVG wrappers embedding WEBP masks. These OpenAI-generated
glyphs retain the exact reviewed pixels. Saved selections and source/output hashes
are in `dev/icons/review/candidates/batch-64/reviewed-installed.json`; all reviewed
decisions, including eleven revision requests and one pending glyph, are archived
in `dev/icons/review/candidates/batch-64/reviewed.json`.

Kuloodporność's subsequent GM approval was installed with the same exact-pixel

Its saved selection and hashes are in
`dev/icons/review/candidates/batch-64/reviewed-addendum-installed.json`; the later
decision snapshot is `dev/icons/review/candidates/batch-64/reviewed-addendum.json`.

Eighteen exact GM-approved Batch 65 glyphs were installed on 2026-10-12 as

These OpenAI-generated glyphs retain the reviewed pixels. Saved selections and

## Token art

Bestiary token art is original work, borrowed (by reference, not copy) from `dnd5e`'s own
top-down token set where it fits, or a clearly-marked placeholder otherwise. Full sourcing rules,
including why `dnd5e`'s Forgotten Adventures tokens are **referenced by path and never copied

[`tokens/README.md`](tokens/README.md).

## Chase-board artwork

Nevada scenery in `ui/poscig/themes/pustynia/` is original AI-generated raster art made with
OpenAI's built-in image-generation tool (2026-10-05): road/terrain, hills, transparent desert
plants, roadside upper structures and windblown dust. Prompts and the dust edit are preserved in
`dev/art/poscig-nevada/prompts.json`; `pack.py` only converts to WEBP and records alpha sprite
bounds. Runtime compositing blends bitmap edges and crops foreground bases; it draws no scenery.
All assets use the same approximately 45-degree camera and upper-left sunlight. No campaign
vehicle art or third-party art is copied into these assets.

The streamed variety pool adds ten generated WEBPs: road and landscape variants, twelve new
foreground cutouts and four road overlays. `dev/art/poscig-nevada/variety-prompts.json` records
the prompts and overlay edit; `catalog.json` and `pack-variety.py` build their manifest. Existing
approved bitmaps are retained. Runtime asset selection and compositing add no drawn scenery.

The Nevada road edge was edited with the same built-in image model to preserve opaque rocks and
vegetation inside an authored alpha contour; `edge-prompts.json` records the edit. Urban scenery
adds fifteen original generated WEBPs under `ui/poscig/themes/przedmiescia/`: four roads,
four ruined districts, twenty foreground cutouts, four pavement overlays and four dust wisps.
Prompts and catalog metadata are in `dev/art/poscig-urban/`. The shared bitmap compositor blends
existing pixels and applies boundary clipping; it draws no scenery.

Winter remains an original procedural canvas drawing in `scripts/scenes/poscig-art.mjs`.
The three transparent WEBP vehicle fixtures in `ui/poscig/vehicles/` are original geometric
drawings generated by `dev/e2e/gen_poscig_art.py` (Pillow). They contain no campaign artwork or
third-party images and are covered by this repository's MIT license.
