# Roboto Mono (SIL OFL 1.1)

The NOE interface sets every number, counter, cost and technical label in Roboto Mono
(`PLAN_m9_style.md` D11, token `--noe-font-num`). Roboto and Roboto Condensed come with dnd5e;
Roboto Mono does not, so it ships here.

The rest of the module stays MIT ([../../LICENSE](../../LICENSE)). The fonts are redistributed
unmodified and are not sold on their own (OFL §1); the name "Roboto Mono" is used only to refer
to the unmodified fonts.

Earlier releases of Roboto Mono were Apache-2.0; the current Google Fonts release, which these
files are, is OFL 1.1. The plan's D11 names the older licence — this folder records what ships.
